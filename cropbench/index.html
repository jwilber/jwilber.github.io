Can a language model run a farm?

CropBench drops a tool-calling agent onto one to three fields for one to three seasons inside a deterministic crop simulator (WOFOST 8.1 through PCSE). It plants, fertilizes, irrigates, tests soil, reads forecasts and harvests through JSON tools. The reward is verifiable: profit under fixed weather, reported in dollars per hectare-season and relative to a rule-of-thumb standard-practice farmer (SP score 1.0 = farms like the baseline).

Scores are against a crop model, not real fields. The economics layer (prices, costs, rotation penalties, leaching proxy) is a benchmark construct.
